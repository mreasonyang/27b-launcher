## 环境与隔离方式

- 本机 Apple Silicon、24 GB 内存。使用 computer use 操作真实原生窗口；日常聊天使用内置 Browser，两条引导聊天使用 Brave。
- 空目录与已有模型状态采用独立 Bundle ID、偏好和模型目录，由同一生产代码的 Debug 构建测试。发布版忽略测试目录环境变量。

- 原生聊天按钮调用系统默认浏览器；测试期间临时选择 Brave，完成后恢复原默认浏览器。没有操作 Chrome 页面。
- 最终 Release 安装到 `~/Applications/27B Launcher.app` 后，从该路径直接操作复测；安装目录与发布构建逐文件一致。该复测不等于在另一台全新 Mac 上重新安装。

## 本轮修复

0.10.9–0.10.11 的修复已包含在最终源码中：

- 分离不同复制控件的反馈；过期反馈复原，字段提供辅助功能反馈。
- 缺失遥测显示未知，真实零仍显示数值；统计数字使用所选语言格式。
- 启动参数尚未知时不误报 LAN；校验结果在显示时本地化。
- 续传列出复用组件，并明确总大小标签。
- 关闭最后窗口后保持应用运行，支持重新打开主窗口。
- 模型加载进程提前退出时结束等待，恢复重试并提示日志／校验。
- 当前引导步骤及时更新；尚未创建的默认目录不再误报为存储故障。
