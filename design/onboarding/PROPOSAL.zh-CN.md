# 首次使用引导：当前行为规范

适用版本：**0.10.11 (40)** · 更新日期：2026-09-30。

本文按当前实现重写，保留原文件名作为文档入口。早期方案中的日常主界面折叠、自动启动并聊天、已有模型跳过引导，以及引导页滚动布局均已撤销。验收结果见 [实现与验证](REVIEW.zh-CN.md)。

## 目标与范围

首次使用按“准备 → 安装与加载 → 开始聊天”推进，让用户知道下载量、保存位置、当前进度和下一步。引导直接使用真实安装器和服务状态。正常全新安装只需确认下载，准备完成后再点击打开聊天；不自动打开浏览器或提交示例问题。

日常主界面保留现有布局：运行指标、OrcaBonsai 和网络卡片直接展示。“启动模型”只启动服务，打开聊天是单独操作。引导不改变登录启动和网络偏好；没有保存设置时，OrcaBonsai 默认启用、强度为 2.0×，已有选择保留。

## 入口与完成条件

| 当前状态 | 显示与行为 |
| --- | --- |
| 引导未完成，缺少组件 | 准备页，下载缺失或已确认损坏的组件 |
| 引导未完成，已有可用模型 | 启动／聊天引导，复用文件，不重复下载 |
| 已选择“稍后设置”，文件仍未就绪 | 延期设置页；退出重开保留选择，可点击“继续设置” |
| 引导已完成，文件就绪 | 日常主界面 |
| 帮助菜单“快速入门” | 主动重新显示引导，按当前文件和服务状态选页 |
| 必要组件缺失或损坏 | 回到对应准备／修复流程；完成标记不能绕过运行条件 |

`onboardingCompleted` 与文件存在状态独立。没有记录过完成的安装，即使已有模型，也会显示一次引导。文件就绪时点击“进入主界面”，或“开始聊天”成功向系统发出打开请求，记录完成。未完成就退出，下次继续；延期不记录为完成。

打开请求成功仅表示系统接受该请求。首次对话是否得到回复需要单独在浏览器验收，应用不采集聊天内容来判断引导完成。

## 页面行为

### 准备页

- 显示实际架构和内存、缺失组件的下载总量、所需空间、目标卷可用空间及完整保存路径。
- 完整首次下载约 7.86 GB，所需磁盘空间还包括解压、临时文件和安全余量。点击下载时重新检查空间，不能只依赖先前显示的值。
- “查看下载内容”通过浮层列出四个组件，不增加主页面高度。已有组件的复用说明包含实际名称。
- 默认目录尚未创建时，设置中的占用状态为“安装时自动创建”；自定义位置失效仍显示不可用。
- “下载并准备”连续执行下载、校验与首次加载。“稍后设置”保存延期选择。
- 首次下载前不能选择其他模型目录；安装完成后通过设置迁移。

### 下载与加载

下载显示实际进度、字节数、可用的速度和剩余时间。暂停后保留进度；有续传记录时，组件体积标签使用“待完成组件总大小”，不能把它误读成尚需传输的字节数。校验、配置和加载使用各自阶段提示，下载达到 100% 不代表服务就绪。

下载可暂停，其他阶段根据实际能力提供取消准备。关闭窗口后继续下载和监控；从 Dock 重新打开应用恢复窗口。退出应用会结束下载和监控，重开后可继续下载；已运行的模型服务继续运行。

全新安装完成后自动加载，并停在就绪页等待用户操作。已有文件首次进入引导时，服务未运行则提供“启动模型”。受管理进程在加载中退出时，立即结束健康等待，提供错误、日志和重试入口；首次加载失败不会在用户阅读错误时反复自动启动。

### 就绪与连接

只有服务健康、已确认本机聊天可用时，显示“开始聊天”、示例问题和连接卡片。API 地址与真实模型 ID 直接展示，各有复制按钮。模型 ID 从 `/v1/models` 获取，保留完整值和大小写；读取失败可原地重试。

本机客户端选择 OpenAI 兼容服务，填写显示的地址和模型 ID。本机连接无需密钥；客户端强制必填时可填写 `local`。LAN 模式或运行参数未知的服务提供状态说明，引导用户进入主界面检查连接／接管选项，不修改监听范围。

示例、API 地址和模型 ID 的复制反馈约两秒后复原；语言切换清除旧示例复制反馈。这只复原按钮状态，不清除剪贴板。浏览器打开失败时保留重试与复制地址入口。

## 错误恢复

| 场景 | 当前行为 |
| --- | --- |
| 不支持的架构或低于最低内存 | 提示具体原因，禁用下载；16–31 GiB 为提醒，允许继续 |
| 空间不足或容量读取失败 | 展示不足或错误，重新检查通过前不能开始 |
| 网络中断／持续下载错误 | 有限重试，保留可续传数据，提供后续操作 |
| 同大小但内容损坏的文件 | 常规检查不等于完整哈希；在设置执行文件校验，按结果修复损坏组件 |
| 加载失败 | 保留已下载组件，查看日志、校验或重试启动 |
| 自定义存储卷丢失 | 指明位置问题，不悄悄切换到默认路径 |
| 外部服务／未知启动参数 | 不冒充已确认可聊天，引导进入主界面处理 |
| 第二个应用实例 | 显示实例冲突，禁用管理操作 |

## 布局、语言与可访问性

采用原生单窗口布局。引导移除页面级滚动，基准最小窗口为 800 × 560 pt，主要操作和连接信息直接可见；辅助功能模式允许随内容调整高度。下载明细使用浮层。

支持简中、繁中、英语和西语、系统／浅色／深色外观。阶段条提供当前步骤的辅助功能值，复制字段暴露反馈。错误和状态同时使用文字，不仅靠颜色表达。完整键盘走查与 VoiceOver 人工验收尚未完成，不能从辅助功能树检查推断其全部通过。

自动布局检查以 800 pt 宽度测量自然内容高度，覆盖四语种和多种错误状态；真实窗口检查只覆盖验收记录列出的组合。
